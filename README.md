# Chocokraff - Catálogo Navideño

Catálogo web estático de **Chocokraff - Detalles Personalizados** con productos navideños (velas, decoración, chocolates, tazas y detalles personalizados).

## Características

- Catálogo responsive con filtros por categoría y búsqueda.
- Ficha de producto al hacer clic: imagen completa, descripción, medidas y precio.
- Botón de pedido directo por WhatsApp en cada producto.
- Sección de métodos de pago, personalización, envíos y contacto.
- Estilo premium en tonos café y dorado, con fondo navideño.

## Vista previa local

Abre `index.html` en el navegador o ejecuta `Abrir-Catalogo.bat`.

También puedes usar un servidor local:

```powershell
python -m http.server 8080
```

Luego visita `http://localhost:8080`.

Este proyecto es un sitio estático y puede publicarse en Vercel, GitHub Pages u otro hosting estático.
